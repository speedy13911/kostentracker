# 💶 Kosten-Tracker

Fixkosten, Abos und Sparziele im Blick – direkt im Browser, ohne Anmeldung.

👉 **App öffnen:** https://speedy13911.github.io/kostentracker/

## ⚠️ Die Zahlen sind nur Beispiele
Beim ersten Öffnen siehst du **Beispieldaten** (z. B. Netflix, Strom, Bausparvertrag).
Sie sind frei erfunden und dienen nur zur Veranschaulichung.

Zum Starten mit eigenen Daten: **⚙️ Daten → 🗑️ Alles löschen** und dann eigene Posten anlegen.

## 🔒 Wo liegen deine Daten?
- Alle Eingaben werden **nur lokal in deinem Browser** auf deinem Gerät gespeichert (`localStorage`).
- **Nichts wird an GitHub oder einen Server übertragen.** Niemand außer dir sieht deine Daten, auch nicht der Betreiber dieser Seite.
- Jeder Nutzer hat seine **eigenen, getrennten Daten**.
- Die Daten gelten nur für **diesen Browser auf diesem Gerät**. Ein anderes Gerät oder ein anderer Browser startet leer.

## 💾 Daten sichern
Weil die Daten nur im Browser liegen, gehen sie verloren, wenn du die Browserdaten löschst.
Sichere sie deshalb regelmäßig:
- **⚙️ Daten → Export (JSON)** speichert eine Sicherungsdatei.
- **⚙️ Daten → Import (JSON)** stellt sie wieder her oder überträgt sie auf ein anderes Gerät.

📱 **iPhone-Tipp:** In Safari auf **Teilen → Zum Home-Bildschirm** tippen und die App immer über das Icon starten.
Safari löscht sonst die Daten von Webseiten, die etwa 7 Tage nicht geöffnet wurden.
